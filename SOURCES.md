# Sources and licenses

## Implementation
Original MoonBit implementation for this local candidate; no Python, DendroPy, Biopython, forester or other project's source is embedded in the runtime. Apache-2.0 in LICENSE. The library imports MoonBit core/string, core/bigint and core/json; the plan-document CLI also uses core/env. No third-party Mooncakes packages are used. Native domain algorithms are established methods, not claimed as newly invented algorithms. The round07 numerical checks use Python's standard-library Fraction to establish independently rounded binary64 path sums; Python remains validation-only.

## Standards and algorithm references
- PHYLIP Newick primary description: https://phylipweb.github.io/phylip/newicktree.html . This project specifies its exact restricted profile in README; it does not claim byte-preserving import or all Newick dialects.
- DendroPy RF API: https://jeetsukumaran.github.io/DendroPy/library/treecompare.html . Rooted descendant clades and unrooted normalized splits are intentionally different; shared TaxonNamespace and explicit rooting are enforced by the reference adapter.
- DendroPy Fitch state-set model: https://jeetsukumaran.github.io/DendroPy/library/parsimony.html . Missing observations are unconstrained sets; this implementation restricts topology to full binary rooted trees and returns a single optimum witness, not all global optimum state sets.
- Bio.Phylo BaseTree API: https://biopython.org/docs/latest/api/Bio.Phylo.BaseTree.html . Only the defined common domain is compared. Biopython defaults and node ordering are not this library's contract.
- NIST full binary terminology: https://xlinux.nist.gov/dads/HTML/fullBinaryTree.html . Leaf outdegree0, internal outdegree2; no completeness/balance assumption.
- Faith PD: https://scikit.bio/docs/latest/generated/skbio.diversity.alpha.faith_pd.html and the author's clarification https://pmc.ncbi.nlm.nih.gov/articles/PMC2674672/ . Rooted branch union includes ancestry above the selected LCA to the study root. The native implementation uses selected taxon presence only, not abundances; source edges are reported for audit. No scikit-bio or BioSeqs implementation source is copied.
- Marginal PD/complementarity: https://pmc.ncbi.nlm.nih.gov/articles/PMC4290425/ (Faith, 2015). Gain relative to an existing species set is implemented by the rooted branch-union definition: sum additional-covered edges not already covered by the baseline. This is an established measure, not a new algorithm claim or optimal conservation-selection procedure. The round09 report records the bounded primary-source/registry inspection and access limitation.
- Greedy PD background: Steel's author-repository paper https://ir.canterbury.ac.nz/server/api/core/bitstreams/5c2234bc-b641-46b9-a492-d134988ac7d1/content and Minh et al. https://academic.oup.com/sysbio/article-abstract/55/5/769/1664851 . The former's stated theorem starts with an unrooted maximal-distance pair; this library's rooted baseline/candidate API specifies its own deterministic stepwise rule. No unqualified transfer to weighted constraints, optimized-time claim or source-code copying is made.

External validation installed biopython==1.88 and dendropy==5.0.8, with package versions/logs/source hashes in the implementation-03 execution report. DendroPy source is BSD-3-Clause. Biopython uses its License Agreement and optional BSD terms on specified files. Those packages are not bundled in this project's source distribution. Their sample-data licensing is not used as a shortcut to relicense research data.
